# Primer3 validation inputs

The authentic reference is the complete 628-base human HBB mRNA **NM_000518.5**,
retrieved as a versioned FASTA from NCBI RefSeq. Its original header, wrapping and
bytes are retained. No patient sequence or individual-level data is included.
Boulder IO cases retain every reference nucleotide and add declared design
parameters; selected primers are generated by the unchanged native executable,
not stored as hand-written result goldens.

The pinned Primer3 2.6.1 source archive supplies complete upstream regression
inputs for internal oligos, new tasks including `check_primers`, acceptable
regions, overhangs and annealing temperature, plus the original thermodynamic
configuration tables. These regression examples are labelled `upstream`; they
are not assumed to be experimentally measured sequences. The small repeat
library consists of explicitly documented HBB slices and is an artificial
specificity test. The synthetic masker index contains all 256 four-base words
with a deterministic artificial count rule; it tests the original index reader
and masking algorithm, not a human genome frequency model.

`sources.lock.json` binds original source bytes, archive revision and member
hashes. `fixture-sources.json` describes every transformation and the resulting
files are bound by `manifest.json`. No scientific output goldens are generated.

```sh
python3 scripts/fetch-primer3-test-data.py --verify
python3 scripts/fetch-primer3-test-data.py --fetch --regenerate
```

Verification is offline. Regeneration uses cached checksum-verified sources,
fetching only when requested; expected identities are never changed unless
`--update-manifest` is explicitly supplied. Unexpected files also fail identity
verification. See `provenance/DATA_REUSE.md` for attribution and reuse notes.
