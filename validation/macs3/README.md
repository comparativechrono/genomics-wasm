# MACS3 3.0.5 scientific equivalence

`node scripts/validate-macs3.mjs --engine node --dataset all` runs every case. Chromium, Firefox and WebKit use the same worker runtime and require no cross-origin isolation. Set `MACS3_PYTHON` to the pinned CPython 3.14.2 interpreter. `scripts/fetch-macs3-test-data.py --verify` checks the frozen dataset and deterministic recipe before running.

The 39-case plan exercises all 14 computational subcommands, not just their help screens. It includes single-end/model/fixed-shift/broad/control-free/paired-end/FRAG/barcode peak calls; single/paired/BAM coverage; duplicate filtering and seeded sampling; predicted fragment length and full model vectors; eight score comparisons; bedGraph arithmetic and peak/differential calls; summit refinement; Gaussian and Poisson HMM training, complete model export, reload, posterior tracks and state/region decoding; and variant calling with local assembly off/on/auto (including a real two-process native pool). Three additional sparse arithmetic regressions cross 32-bit boundaries using only five input records: paired fragment-mean prediction, bedGraph p2q, and ScoreTrack qpois over 5 billion aggregate bases. They require at most about 42 MiB in the native tests. An invalid-command test verifies clean failure reporting.

Every case executes independently against an unmodified same-version native wheel, a native wheel with the portability patch, and WebAssembly. Native launchers select a real spawn multiprocessing pool, compatible with Python 3.14 and avoiding its forkserver socket requirement. This is not the serial WebAssembly patch. HMM reload takes each target's own newly trained model. All result files, invocations, inputs, dependency bytes, runtime sources, comparator, dataset manifest, native installed package trees and distribution assets are hash-bound into reports. Report files live under unique run IDs; stable summaries are published only when a run finishes. A failure never counts as a successful empty result.

## Scientific comparison policy

Chromosome identifiers, intervals, row order, summits, peak calls, names, state labels, counts, variant REF/ALT/genotypes, read depths and discrete model metadata must match exactly. Every requested scientific artifact must exist and pass its structural and non-vacuity contract. Gaussian models include every covariance entry, transition and starting probability; Poisson models include every rate. Both include full dimensions, normalized state probabilities, semantic state indices and bin size. Covariance checks accept the positive-semidefinite matrices that upstream permits with decoding jitter and reject indefinite matrices.

Printed continuous scores use absolute tolerance 1e-5 plus relative tolerance 1e-6. MACS writes many bedGraph scores to five decimal places; this permits at most a final printed decimal near small values and bounded relative floating-point differences for larger statistics. HMM parameters use absolute 1e-7 plus relative 1e-5 to accommodate float/BLAS rounding in iterative estimation; structure and final genomic decisions remain exact. Integer pileup coverage uses zero tolerance. Reports disclose compared field counts, maximum absolute/relative differences and the number of differences accepted by tolerance. Tolerance is specified before native/WASM comparison and cannot hide a changed coordinate, genotype or state decision.

Independent truth checks cover three exact synthetic peak intervals; arithmetic multiplication, maximum and replicate mean; integrated coverage equalling source read-count × extension or the exact sum of paired fragment lengths; posterior probabilities in [0,1]; and authentic upstream-supported SNP/inserted alleles in callvar. The wide p2q check independently calculates the pinned upstream rank-one correction over exactly 5 billion bases; it preserves upstream behavior, including the rank counter that this release leaves at one. Other real-data cases require nonempty scientific output and full native equivalence, not an invented biological ground truth. The upstream random-sampling implementation rounds by track partitions: requested 1000 produces 999 records for these pinned fixtures, and this count is asserted explicitly. Its single-chromosome fixtures also avoid upstream set iteration order affecting seeded multi-chromosome single-end sampling.

UCSC display track lines, VCF date/invocation headers and XLS invocation comments are the only metadata exclusions; biological rows and scientific metadata remain. R model vectors p/m/ycorr are compared numerically; xcorr lags and alternative fragment lengths remain exact. Gaussian training uses default fragment-mixture EM and upstream automatic training region selection on authentic yeast chrI. Poisson uses a declared whole-chromosome training interval with fixed upstream fragment mixture; both use seed12345 and 1000-base decoding flanks.

The comparator unit suite mutates coordinates, rank/order, sequence calls, depths, numeric fields, model dimensions and full covariance/transition structures. It also checks malformed outputs, nonfinite values, unnormalized probabilities, path traversal, and identical-but-wrong synthetic arithmetic. Native exploratory runs are not substitutes for recorded four-engine equivalence; packaging gates require complete verified reports from all engines.
