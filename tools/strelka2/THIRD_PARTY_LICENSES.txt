The main upstream source archive contains the exact third-party archives in
redist/. Their hashes are recorded as bundledDependencies; these are included
once inside that archive. Standalone zlib and CPython source archives are also
included. Host compiler executables are build-time requirements, not part of
the browser runtime.

Port changes (2026): a separate cross-compilation build layer; delete an unused
RapidJSON assignment operator that attempts to assign const members; use explicit
64-bit Strelka run-statistics counters so wasm32 does not narrow native counts;
reject bgzip thread counts above one in the serial browser package.
The variant-calling algorithms, model coefficients and workflow source used by
the native oracle are unchanged. See README.md for supported execution scope.
