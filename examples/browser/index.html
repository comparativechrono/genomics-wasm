Genomics WASM

Run BWA or FreeBayes in your browser.

This example runs the compiled tools in a worker. Files stay in this browser tab and are cleared when you reload. Start with a small reference and a small set of reads.

Command

Use the uploaded filenames exactly. Each array entry is one argument; shell pipes and redirection are not interpreted.

These files will be available to the next command. Standard output is always available to download.

Files

For BWA, index the reference first, then run alignment. For FreeBayes, add a reference, its FASTA index, a coordinate-sorted BAM and its index.
