Repeat analysis in the browser

Call repeat genotypes with ExpansionHunter and inspect the supporting reads with REViewer.

ExpansionHunter 5.0.0, SAMtools 1.21 and REViewer 0.2.7 run locally in this browser. Run the example presets in order: call repeats, sort and index the generated alignments, then draw the read evidence. Reloading clears this tab's files.
