Checking browser support…

For a local copy, run python3 examples/plink2/serve.py from the package folder and open the printed address. Hosted copies require cross-origin isolation; see hosting instructions.

This build supports file conversion, quality control, LD and regression with one or two compute threads. PCA and other LAPACK-dependent commands are unavailable in this build. The 2 GiB WebAssembly heap is a limit, not a guarantee that a dataset fits.
