DESeq2 in the browser

Run R code with gene counts and sample information.

This example uses DESeq2 in webR. R runs in this browser tab. Uploaded files stay here and are cleared when you reload the page.

Data

Use raw integer gene counts, with genes in rows and samples in columns. The first column holds the gene IDs. In the sample table, the first column holds sample IDs matching the count-table headings. Both files need a header row and tab-separated columns.

R code

The two uploaded files are available as counts.tsv and samples.tsv. Edit the design and contrast for your own experiment. The example compares treated with untreated samples while accounting for cell line.

This is ordinary R code. Files written in the working directory become downloads. DESeq2 and its bundled dependencies are available; other R packages need a compatible webR build.
