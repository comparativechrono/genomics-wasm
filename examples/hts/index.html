BCFtools and SAMtools in the browser

Inspect variants, extract VEP annotations, and work with family and alignment data.

BCFtools, its built-in plugins, SAMtools and HTSlib utilities run locally in this browser. Load the examples or add files, choose a version, and run a command. Reloading clears this tab's files.

Command

Plugins use the usual +name syntax. Each array entry is one argument. Pipes and shell redirection are not interpreted.

Standard input and output

Standard output retains its exact bytes, including compressed VCF and BAM. Use a different output filename when transforming an input file.

Successful outputs stay available for later commands and other versions. Explicit output files must be regenerated; folder collection can also include existing files.
